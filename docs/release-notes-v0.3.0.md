# Orvexa Studio v0.3.0

**Orvexa Studio v0.3.0** переводит IDE и консольный компилятор с бренда Atlas на Orvexa и синхронизирует инструменты разработки с возможностями Orvexa Runtime v0.7.5. Выпуск сохраняет совместимый формат исходных проектов и `.atp`-пакетов, одновременно делая новые права Runtime доступными и проверяемыми в интерфейсе Studio.

| Направление | Что изменилось |
|---|---|
| Бренд | Atlas Studio, Compiler и Updater переименованы в **Orvexa Studio**, **Orvexa Compiler** и **Orvexa Updater**. |
| Версия | Версия IDE и консольного компилятора обновлена до `0.3.0`. |
| Runtime API | Добавлены разрешения Orvexa Runtime v0.7.5 в интерфейс, сборщик и консольный компилятор. |
| Шаблоны | Новый проект создаётся с совместимым примером Orvexa Runtime v0.7.5. |
| Надёжность | Добавлена проверка кодирования и декодирования динамических UI-событий с точечными ID плагинов. |

## Новые разрешения Runtime

Страница разрешений Studio теперь позволяет автору пакета явно заявить новые безопасные возможности. Выбранные значения сохраняются в `atlas-project.json`, проверяются сборщиком и попадают в manifest `.atp`. Неизвестные разрешения по-прежнему не принимаются.

| Разрешение | Назначение |
|---|---|
| `ui.feedback` | Неблокирующие уведомления и декларативный UI. |
| `instances.read` | Безопасные метаданные игровых экземпляров. |
| `content.read` | Агрегированная статистика контента экземпляра. |
| `content.refresh` | Запрос обновления сводки контента. |
| `launcher.navigation` | Переход к разрешённым разделам Orvexa Launcher. |

## Orvexa Code

Локальный компилятор Studio и консольный Orvexa Compiler синхронизированы с моделью динамических событий Runtime. Поддерживаются события экземпляров и контента, а клики декларативных контролов проходят строгую проверку, в том числе для идентификаторов плагинов вида `org.example.plugin`. Это исключает расхождения между проектом, созданным в Studio, и исполнением в Orvexa Launcher.

Новый стартовый проект использует проверяемый минимальный набор разрешений и служит рабочей отправной точкой для создания плагина. Справочные материалы Orvexa Code также обновлены вместе с Launcher.

## Совместимость и проверка

Расширения исходников `.atlas`, имя манифеста `atlas-project.json` и формат ATBC 2 сохранены для совместимости с существующими инструментами и пакетами. Обновлены отображаемые названия, исполняемые файлы, CI-артефакты и путь обновления Studio.

Нативная сборка Orvexa Studio успешно проходит все **5 из 5** регрессионных тестов, включая UI, упаковку, отправку в каталог, консольную справку Compiler и Updater.
